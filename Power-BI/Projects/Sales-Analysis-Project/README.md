# Sales Analysis Dashboard (2020-2022)

## Project Overview
This Power BI project provides a comprehensive overview of sales performance, profitability, and quantity distribution.
It features interactive visualizations to track top-selling categories (like Monitors and CPUs) and analyze performance by brand and supervisor. 

## Key Features
* **Geographical Analysis:** A map view showing the "Sum of Sales" across different states in India.
* **Product Performance:** A bar chart highlighting quantity sold by category (e.g., Monitor, Mobile, CPU).
* **Market Share:** A donut chart displaying Total Sales by Brand (e.g., MSI, Intel, Samsung).
* **Key Metrics:** Quick-glance cards for Total Sales (99M), Profit (25M), and Total Orders (2597).

## Tools Used
* Power BI Desktop
* Data Modeling & DAX
* Interactive Data Visualization
