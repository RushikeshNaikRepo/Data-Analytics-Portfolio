This Mobile Sales Dashboard provides a comprehensive overview of retail performance, tracking 669M in Total Sales across 40K transactions. Built in Power BI, the report utilizes a custom calendar table to enable seamless time-series analysis, such as the "Month-wise Total Quantity" trend. Key technical features include DAX-driven KPIs for Average Price and Quantity, as well as multi-dimensional filtering by Brand, Model, and Payment Method to uncover consumer purchasing patterns.
